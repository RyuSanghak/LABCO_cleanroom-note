ISO 14644-1:2015 는 분류 측정에 **ISO 21501-4 에 따라 교정된 카운터**를 요구합니다. 교정 성적서에 무엇이 적혀 있어야 하는지 알면 장비 선택과 감사 대응이 쉬워집니다.

## ISO 21501-4 란

광산란식 부유 입자 카운터(LSAPC)의 **교정 방법과 성능 요구사항**을 정한 표준입니다. 2007년 제정, 현행판 2018년. 핵심은 장비마다 제각각이던 "입자 크기"와 "개수"를 서로 비교할 수 있게 만드는 것입니다.

## 검증 항목과 허용 기준

| 항목 | 요구사항 | 뜻 |
|---|---|---|
| 크기 설정 오차 | ≤ 10% | 0.5 µm 채널이 실제로 0.5 µm PSL 입자에서 열리는지 |
| 계수 효율 (최소 검출 크기) | 50% ± 20% | 가장 작은 채널에서 입자 절반을 세면 정상 |
| 계수 효율 (최소 크기의 1.5~2배) | 100% ± 10% | 조금 더 큰 입자는 거의 다 세야 함 |
| 크기 분해능 | ≤ 15% | 같은 크기 입자가 인접 채널로 흩어지는 정도 |
| 영점 계수 (false count) | 충분히 낮을 것 | 무입자 공기에서의 가짜 계수. 제조사 사양 예: 5분에 1개 이하 |
| 유량 | 불확도 ≤ 5% | 유량이 틀리면 농도가 그대로 틀림 |
| 최대 농도 / 동시통과 손실 | 제조사 명시 농도에서 검증 | 입자가 많을 때 둘을 하나로 세는 오차 한계 |
| 교정 주기 | 1년 이하 | 연 1회가 사실상 표준 |

계수 효율은 **기준 장비와의 비교**로 확인하고, 크기 설정은 **PSL 표준 입자**와 펄스 높이 분석(PHA)으로 확인합니다.

## 성적서에서 볼 것

- **표준 번호와 판**: "ISO 21501-4:2018 에 따름" 명시
- **추적성**: 사용한 PSL 입자와 기준 장비의 교정 이력
- **항목별 측정값과 허용 기준**: 합격/불합격만 있는 성적서는 부족
- **교정 전(as found)·후(as left) 값**: 교정 전 값이 기준 밖이면 그 사이 데이터의 신뢰성 검토 필요
- **유효 기간**: 분류 측정일이 유효 기간 안에 있어야 보고서가 인정됨

## 실무 포인트

- 국내에서 교정받을 수 있는 장비가 운용이 쉽습니다. 해외 발송은 수 주 공백이 생깁니다.
- 모니터링 장비가 많으면 **교정 일정을 분산**해 동시에 빠지지 않게 합니다.
- 교정 외에 **현장 점검**(유량 확인, 영점 필터 테스트)을 정기적으로 하면 교정 사이의 이상을 조기에 잡습니다.
- 사양서의 "0.3 µm 50%" 는 이 표준의 정상 기준입니다. → [광산란 원리](/articles/particle-counter-principle/)
